
# 🧭 Decision Compass

**Decision Compass** is a modern, interactive frontend web application designed to help users make better everyday decisions. It combines career exploration, technology comparisons, hobby recommendations, and a weighted decision-making tool in one intuitive platform.

The project focuses on **UI/UX design, responsive layouts, and interactive functionality**, creating an experience that feels like a real-world web application.

## ✨ Features

- 🎯 **Career Matcher** — Explore career options based on personal interests and preferences.
- 💻 **Tech Comparison** — Search, filter, sort, and compare technology products.
- 🎨 **Hobby Matcher** — Discover hobbies based on individual interests.
- ⚖️ **Decision Tool** — Evaluate options using weighted criteria and calculated scores.
- 📱 **Responsive Design** — Adaptable layouts for desktop, tablet, and mobile devices.
- ⚡ **Interactive Interface** — Dynamic content, input validation, filtering, comparison tools, and instant results.

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| HTML5 | Page structure and semantic markup |
| CSS3 | Styling, layouts, animations, and visual design |
| JavaScript | Interactive features, dynamic content, and calculations |
| Bootstrap | Responsive grid system and UI components |

## 🎨 Design Philosophy

Decision Compass was developed with a strong emphasis on frontend design and user experience.

- Consistent visual identity across pages.
- Clear navigation and organized layouts.
- User-friendly interactions and feedback.
- Responsive components and readable typography.
- A polished interface designed to resemble a real-world web application.

## 💾 Data & Functionality

The application uses **JavaScript arrays and objects** to store sample data, including technology products and recommendation options. This data powers frontend features such as filtering, comparisons, matching, and decision calculations.

The project does not currently use a real database or backend API. Data processing and interactive functionality are handled on the client side.

## 🚀 Getting Started

### Run Locally

1. Clone or download this repository.
2. Open the project folder in your code editor.
3. Open `index.html` in your browser.

For a better development experience, you can use the **Live Server** extension in Visual Studio Code.

## 📌 Project Goal

The goal of Decision Compass is to combine thoughtful UI/UX design with practical JavaScript functionality to create a visually polished, interactive frontend application that makes everyday decision-making easier.
